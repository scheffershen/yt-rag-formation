Context assembly and evidence budgets

A quick, practical guide to making this engineering decision.

中文 用于本课工程决策的证据速查表。

One-line rule

A retrieved source is not useful evidence if truncation removes it before the model sees it.

一句话规则：如果截断把检索到的来源删除了，它就不再是模型可用的证据。

Core terms

TermMeaning
Context assemblyTurning backend results into the text sent to the answering model.
Evidence budgetThe maximum context allowed by characters, tokens, latency, or cost.
Source survivalWhether the evidence needed for an answer is still present after formatting and truncation.

Evidence card

NeedRecordDon't claim
BaselineCommand, configuration, observed resultThe baseline is a target.
ChangeOne hypothesis or decisionYou can tell what caused the result when several things changed.
MetricList each source, its order, formatted size, and whether it survives the context budget.One metric tells you everything about quality.
SafetyA failure and a regression caseA fluent answer proves the system is reliable.

证据卡：记录基线、一次改动、指标和安全回归；不要把单一指标等同于整体质量。
