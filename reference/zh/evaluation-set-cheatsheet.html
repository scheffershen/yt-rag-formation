可信的 RAG 评估集

一份可靠的 RAG 评估集：在不自欺的前提下衡量企业聊天机器人。

评估五元组

问题 + 类别 + 预期来源 + 必需事实 + 预期行为

对于可回答问题，预期行为是正确且有依据的答案；对于不可回答问题，预期行为是拒答。

参考答案规则

  1. 每一个预期来源都必须真实存在于语料库中。
  2. 每一个必需事实都必须逐字出现在某个预期来源里。
  3. 不可回答的问题，既不能有预期来源，也不能有必需事实。
  4. 检索匹配要依据元数据，而不是文本块里随意出现的文字。
  5. 在比较系统改动的过程中，评估集本身要保持不变。

基本规则：预期来源必须存在；必需事实必须出现在来源中；不可回答问题不能有来源或必需事实；检索匹配应使用元数据而不是任意正文；比较系统改动时保持评估集稳定。

错误的衡量方式

因为向量结果的正文提到了预期文档编号，就把它算作检索成功。

更好的衡量方式

只有当结果的来源元数据标识了预期文档时，才算检索成功。

信任边界

评估工具可能是错误的，却仍然输出看似自信的百分比。因此要测试评分器本身：重音符号、多来源问题、正文交叉引用、缺失引用和拒答。
