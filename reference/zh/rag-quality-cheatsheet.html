RAG QA 质量速查表

一个可靠的 RAG 聊天机器人是一条完整的流水线，而不是一个提示词。

整条流水线

问题 → 检索证据 → 组装上下文 → 生成答案 → 引用来源 → 评估。

答案出错时，首先要问：证据缺失了，还是证据存在但没有被正确使用？

两个质量层次

层级关键问题演示环境信号
检索系统是否返回了所有预期的来源？检索并集 / 各索引命中率
生成答案是否准确陈述了所需事实，且没有自相矛盾？严格与宽松评判准确率
有依据是否引用了支撑答案的文档？来源命中率
安全是否拒答了语料库之外的问题？拒答准确率与幻觉率
运维用户能否快速、稳定地获得答案？延迟 p50 / p95 与 API 错误

正确理解当前演示系统的指标

  • 严格准确率： 只统计判定为 correct（正确）的结果，把它作为核心指标。
  • 宽松准确率： 统计 correct + partial（正确 + 部分正确）。它有助于诊断，但不能替代严格准确率。
  • 来源命中率： 检查最终答案是否引用了所有预期的来源文档。
  • 拒答准确率： 检查系统是否正确拒答了自己回答不了的问题。
  • 幻觉率： 统计系统在面对答不了的问题时，仍然给出回答的频率。

检索失败

正确的文档没有进入答案提示词。改进分块、元数据、查询处理、混合检索、过滤器或排序。

生成失败

正确的证据已经存在，但答案遗漏、混淆或违背了证据。改进上下文组装、指令、答案结构或模型选择。

课程规则

课程规则： 不要因为一个令人印象深刻的答案，就声称提示词改进有效。应该运行评估工具、检查失败案例，并把相同指标与上一次运行进行比较。
