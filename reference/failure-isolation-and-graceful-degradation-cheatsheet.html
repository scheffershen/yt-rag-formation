Failure isolation and graceful degradation

A quick, practical guide to making this engineering decision.

中文 用于本课工程决策的证据速查表。

One-line rule

If required evidence is gone, returning a normal-looking answer is an unsafe fallback.

一句话规则：丢失必要证据后仍返回看似正常的答案，是不安全的降级方式。

Core terms

TermMeaning
Failure isolationKeeping one dependency’s failure from breaking the whole request or hiding what went wrong.
Graceful degradationReturning a clearly limited result when it is safe—for example, vector-only search without pretending it has hybrid coverage.
Fail closedRefusing to answer when a missing dependency means the evidence or authorization cannot be trusted.

Evidence card

NeedRecordDon't claim
BaselineCommand, configuration, observed resultThe baseline is a target.
ChangeOne hypothesis or decisionYou can tell what caused the result when several things changed.
MetricFor each dependency, record the symptom, safe fallback, blocked behavior, user message, and metric.One metric tells you everything about quality.
SafetyA failure and a regression caseA fluent answer proves the system is reliable.

证据卡：记录基线、一次改动、指标和安全回归；不要把单一指标等同于整体质量。
